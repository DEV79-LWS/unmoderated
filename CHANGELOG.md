# UNMODERATED.NET Changelog

## v1.0.8

![UNMODERATED.NET](docs/images/unmoderated-promo.jpg)

UNMODERATED.NET received another round of visual, responsive, and sharing improvements.

- Increased the maximum post and reply length to **7,000 characters including spaces**.
- Updated several interface icons and the favicon.
- Added floating success and error notifications with slide/fade animation.
- Added social profile links to the footer.
- Replaced the original humanoid artwork with new people-and-machine artwork created specifically for UNMODERATED.NET.
- Added a dedicated mobile homepage hero image for screens below **990px**.
- Improved mobile hero positioning, spacing, and minimum height.
- Improved the mobile navigation hover state with a subtle **0.2-second fading dotted underline**.
- Added Open Graph metadata for social sharing.
- Added X/Twitter large-image card metadata.
- Added a dedicated social-sharing featured image.
- Discussion pages now use their own title and an excerpt from the opening post when shared.
- Added various responsive, caching, and visual consistency improvements.

Still experimental. Still evolving. Still red.
